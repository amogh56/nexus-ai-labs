## 🚀 How to Run and View

### Option 1: Direct Browser Opening
Simply double-click or open `index.html` in any modern web browser:
```bash
# Path
C:\AnushaSS\nexus-ai\index.html
```

### Option 2: Local HTTP Server (Node.js)
```bash
# Using npx serve
npx serve "C:\AnushaSS\nexus-ai"

# Or using Python
python -m http.server 3000 --directory "C:\AnushaSS\nexus-ai"
```
